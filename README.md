# PowerShell Basics

Learn to write PowerShell scripts in 12 short lessons. Start by running a single command in a `.ps1` file, then build up to a script that writes a score report.

## Start the course

Download or clone this repository and open `index.html` in a browser. The interface has no build step or dependencies. Install [PowerShell](https://learn.microsoft.com/powershell/scripting/install/installing-powershell) and use a plain-text editor for the exercises. The first lesson walks through setting up a practice folder and running your first script.

## How the lessons work

1. Run the worked example in PowerShell and compare the result with the example output.
2. Change the script or write a short script of your own. Use the hint if you get stuck, then compare with the solution.
3. Answer the quick check and mark the lesson complete when you're ready. The browser saves completed lessons and your current lesson on the same device when local storage is available.

| Section | Lessons |
| --- | --- |
| Getting started | Run a script, store values, use quotes, calculate a total |
| Decisions and repetition | Read input, use conditions, make arrays, write loops |
| Useful scripts | Pipe output, write functions, work with files, build a score report |

The browser displays examples, answers, and output to compare against. Run your scripts in PowerShell.
