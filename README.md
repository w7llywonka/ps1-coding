# Learn PowerShell

Write your first `.ps1` file, then work through the language, its object pipeline, and the tools used to build and maintain PowerShell automation. The course has 42 lessons, 12 unit challenges, and 96 hands-on problems.

## Start the course

1. Download or clone this repository and open `index.html` in a browser. There is no build step.
2. Install [PowerShell 7](https://learn.microsoft.com/powershell/scripting/install/installing-powershell) and use a plain-text editor. The first lesson shows how to set up a practice folder and run a script.
3. Run the worked example in PowerShell. Try the first problem on the new skill, then solve a harder problem that brings in earlier skills. Compare your output before opening the hint or solution.
4. Finish the unit challenge and test the script with a different input or case. The browser saves submissions marked complete on the same device when local storage is available.

Most exercises run locally on Windows, macOS, or Linux. The course labels exercises that need a public API, Windows, or Pester. Remoting exercises run locally first, and the unit reference links to setup for an authorized remote host.

## Course map

| Unit | What you learn | Challenge |
| --- | --- | --- |
| 1. Script basics | Script files, variables, quotes, and arithmetic | Calculate a snack order receipt. |
| 2. Decisions and loops | Input, conditions, arrays, and loops | Count study sessions against two goals. |
| 3. Reusable scripts and reports | Pipelines, functions, and text files | Rank ticket orders and save a report. |
| 4. Types, keys, and patterns | Conversions, null, hashtables, splatting, switch, wildcards, regex, and .NET collections | Validate and price an inventory order. |
| 5. Objects and pipelines | Properties, methods, custom objects, filtering, projection, grouping, measurement, and formatting | Rank teams by time worked. |
| 6. Files and structured data | Providers, portable paths, file discovery, CSV, and JSON | Transform stock records from CSV to JSON. |
| 7. Functions, modules, and classes | Parameters, validation, pipeline binding, scopes, script modules, manifests, enums, and classes | Export a score command for other scripts. |
| 8. Errors, debugging, and tests | Terminating errors, cleanup, output streams, debugging, assertions, and Pester | Build and test an input parser. |
| 9. The shell, tools, and APIs | Help, command discovery, profiles, native arguments, environment, exit codes, and REST | Build a report that runs offline or reads live data. |
| 10. Jobs, parallel work, and remoting | Background jobs, runspaces, throttling, script blocks, and sessions | Summarize files with bounded parallel workers. |
| 11. System administration | Process inspection, Windows services, CIM, and event logs | Export a report of service exceptions. |
| 12. Safe, repeatable automation | Preview, idempotency, secrets, and unattended execution | Build and verify an inventory report that can run on a schedule. |
